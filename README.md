# 🌾 Farming Management System (Java Swing)

A Java Swing desktop application to help manage farming operations — crops, resources, and farm records — through a graphical interface.

> ⚠️ Cleanup note: the repo currently has both a `FarmingManagementProject/` folder and a separate `src/` folder (looks like a duplicate/extracted copy). Recommend keeping only one clean source folder before sharing this repo with recruiters.

## 🛠️ Tech Stack
- Java Swing (GUI)
- IntelliJ IDEA project structure

## ✨ Features
> Update this list with your actual implemented features, for example:
- Add/manage crop and farm records
- Track expenses and yield
- Simple GUI-based data entry and viewing

## 🚀 How to Run
1. Clone the repository:
   ```
   git clone https://github.com/Sandip678/farmingmanagement.git
   ```
2. Open the project in IntelliJ IDEA / Eclipse.
3. Locate the file containing the `main()` method (with the Swing JFrame).
4. Run it directly from the IDE.
